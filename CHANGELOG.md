# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-22

### Added
- Initial release of the Next.js Master Starter Template.
- Full design system integrated with Tailwind CSS v4.
- 50+ accessible UI components (Navigation, Layout, Feedback, Forms, Data Display).
- Support for Dark and Light modes via `next-themes`.
- Comprehensive documentation suite covering Architecture, Customization, Security, and Accessibility.
- Standardized AI coding rules and PR/Issue templates.
