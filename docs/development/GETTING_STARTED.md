# Developer Quickstart

Welcome to the Next.js Master Starter Template.

## Prerequisites
- Node.js >= 18.17.0
- npm >= 9.0.0
- Git

## Setup
1. `npm install` to install dependencies.
2. `cp .env.example .env.local` to set up local environment variables.
3. `npm run dev` to start the development server.

## Scripts Overview
- `npm run dev`: Next.js development server.
- `npm run build`: Production build.
- `npm run start`: Production server.
- `npm run lint`: ESLint check.
- `npm run format`: Prettier format.
- `npm run typecheck`: TypeScript validation.

## Exploring the Codebase
- The entry point is `src/app/page.tsx` and `src/app/layout.tsx`.
- Review `src/components/ui` to see the available primitives.
- Review `src/config/app.ts` to see global app configuration.
