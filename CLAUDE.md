# Coding Instructions & Rules

Refer to `AGENTS.md` for complete directives.

## Critical Execution Directives
- Do not stop after identifying differences. You must actually IMPLEMENT the required fixes across the project.
- Do not give recommendations instead of changes.
- Inspect → compare → identify → implement → test → compare again → refine.
- Repeat the browser comparison cycle until the development system closely matches the production/original system in both UI/UX and functionality.
- Trace discrepancies back to shared components, design tokens, assets, or business logic.
- Preserve existing functionality and architecture.
- Never replace working functionality with placeholder/mocked functionality.
- Never redesign the product without strict instruction.
- Priority: Production Parity > Functional Correctness > Visual Consistency > Responsive Consistency > Performance > Accessibility > Maintainable Implementation.
- Perform work deeply across the entire application.
